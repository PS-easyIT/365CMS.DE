# 365CMS – Projektdokumentation | Abschnitt: Runtime-Einstieg
> **Stand:** 2026-09-14 | **Version:** 3.4.00 | **Status:** Stable | **Update:** 2026-09-14

## English

`CMS/` is the deployable runtime. The web bootstrap, protected configuration, installer, core services, administration, plugins, themes, and runtime assets are located here. Installation-specific secrets, uploads, cache, logs, and backups must remain outside release packages.

## Deutsch

`CMS/` ist die auslieferbare Runtime. Web-Bootstrap, geschützte Konfiguration, Installer, Core-Services, Administration, Plugins, Themes und Runtime-Assets liegen hier. Installationsspezifische Secrets, Uploads, Cache, Logs und Backups gehören nicht in Release-Pakete.
