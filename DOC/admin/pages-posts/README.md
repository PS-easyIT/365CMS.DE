## English

This directory documents content administration. See [PAGES.md](PAGES.md) for pages, [POSTS.md](POSTS.md) for posts, [COMMENTS.md](COMMENTS.md) for comments, and [HUBSITES.md](HUBSITES.md) for hub sites.

All content changes belong to the current admin modules. Do not call database tables or legacy entry scripts directly; use the authenticated UI and its validation and CSRF contract.

## Deutsch

Dieses Verzeichnis dokumentiert die Inhaltsverwaltung. Siehe [PAGES.md](PAGES.md) für Seiten, [POSTS.md](POSTS.md) für Beiträge, [COMMENTS.md](COMMENTS.md) für Kommentare und [HUBSITES.md](HUBSITES.md) für Hub Sites.

Alle Inhaltsänderungen laufen über die aktuellen Admin-Module. Datenbanktabellen oder Legacy-Einstiege dürfen nicht direkt angesprochen werden; verwenden Sie die authentifizierte Oberfläche mit ihrer Validierungs- und CSRF-Prüfung.
