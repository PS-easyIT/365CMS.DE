# 365CMS – Projektdokumentation | Abschnitt: Admin – Inhaltsverzeichnis
> **Stand:** 2026-09-13 | **Version:** 3.4.00 | **Status:** Stable | **Update:** 2026-09-13

## English

The table-of-contents administration is implemented by `CMS/admin/modules/toc/TocModule.php`. It is responsible for the supported TOC data and its admin presentation. Use the module route exposed by the current admin router; do not infer a public content route from this document.

## Deutsch

Die Verwaltung des Inhaltsverzeichnisses wird durch `CMS/admin/modules/toc/TocModule.php` implementiert. Das Modul ist für die unterstützten TOC-Daten und deren Admin-Darstellung zuständig. Verwenden Sie die vom aktuellen Admin-Router bereitgestellte Modulroute; aus dieser Dokumentation darf keine öffentliche Inhaltsroute abgeleitet werden.
