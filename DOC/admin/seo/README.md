# 365CMS – Projektdokumentation | Abschnitt: Admin – SEO
> **Stand:** 2026-09-13 | **Version:** 3.4.00 | **Status:** Stable | **Update:** 2026-09-13

## English

This directory documents the SEO administration. Start with [SEO.md](SEO.md), then use [ANALYTICS.md](ANALYTICS.md) for analytics and [REDIRECTS.md](REDIRECTS.md) for redirect and not-found management.

The runtime modules are in `CMS/admin/modules/seo/`; their views are in `CMS/admin/views/seo/`. Use authenticated admin actions and the current router instead of direct PHP calls.

## Deutsch

Dieses Verzeichnis dokumentiert die SEO-Administration. Beginnen Sie mit [SEO.md](SEO.md), verwenden Sie [ANALYTICS.md](ANALYTICS.md) für Analytics und [REDIRECTS.md](REDIRECTS.md) für Redirect- und Not-Found-Verwaltung.

Die Runtime-Module liegen unter `CMS/admin/modules/seo/`, ihre Views unter `CMS/admin/views/seo/`. Verwenden Sie authentifizierte Admin-Aktionen und den aktuellen Router statt direkter PHP-Aufrufe.
