# 365CMS – Projektdokumentation | Abschnitt: Theme-JavaScript
> **Stand:** 2026-09-14 | **Version:** 3.4.00 | **Status:** Stable | **Update:** 2026-09-14

## English

Theme JavaScript belongs in the active theme's asset directories under `CMS/themes/`. Load scripts through the theme's existing asset/bootstrap mechanism, use scoped selectors, and keep server-side authorization independent of client-side state.

## Deutsch

Theme-JavaScript liegt in den Asset-Verzeichnissen des aktiven Themes unter `CMS/themes/`. Scripts werden über den vorhandenen Asset-/Bootstrap-Mechanismus geladen; Selektoren bleiben begrenzt. Serverseitige Autorisierung darf niemals von Client-Zuständen abhängen.
