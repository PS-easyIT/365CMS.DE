# 365CMS – Projektdokumentation | Abschnitt: Theme-System
> **Stand:** 2026-09-14 | **Version:** 3.4.00 | **Status:** Stable | **Update:** 2026-09-14

## English

Runtime themes are loaded from `CMS/themes/`. Theme administration is implemented by the modules and entry points under `CMS/admin/modules/themes/` and `CMS/admin/themes.php`. Use the companion documents for components, design tokens, JavaScript, and development.

## Deutsch

Runtime-Themes werden aus `CMS/themes/` geladen. Die Theme-Administration wird durch die Module und Einstiege unter `CMS/admin/modules/themes/` und `CMS/admin/themes.php` implementiert. Die ergänzenden Dokumente behandeln Komponenten, Design-Tokens, JavaScript und Entwicklung.
