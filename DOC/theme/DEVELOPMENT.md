# 365CMS – Projektdokumentation | Abschnitt: Theme-Entwicklungsumgebung
> **Stand:** 2026-09-14 | **Version:** 3.4.00 | **Status:** Stable | **Update:** 2026-09-14

## English

Develop against the active runtime theme in `CMS/themes/`. Validate template paths, asset URLs, escaping, responsive behavior, and admin customizer/editor integration before release. Keep installation-specific configuration outside the theme package.

## Deutsch

Die Entwicklung erfolgt gegen das aktive Runtime-Theme unter `CMS/themes/`. Vor einer Veröffentlichung sind Template-Pfade, Asset-URLs, Escaping, responsives Verhalten sowie Customizer-/Editor-Integration zu prüfen. Installationsspezifische Konfiguration gehört nicht in das Theme-Paket.
