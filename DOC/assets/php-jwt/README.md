# firebase/php-jwt

## Kurzbeschreibung

`firebase/php-jwt` wird für API-Authentifizierung und Token-Verarbeitung verwendet.

## Quellordner

- `CMS/assets/php-jwt/`

## Verwendung in 365CMS

- direkte Nutzung in `CMS/core/Services/JwtService.php`
- Einbindung über `CMS/assets/autoload.php`
