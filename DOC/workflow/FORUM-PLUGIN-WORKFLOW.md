# 365CMS – Projektdokumentation | Abschnitt: Workflow – Forum-Plugin
> **Stand:** 2026-09-14 | **Version:** 3.4.00 | **Status:** Not implemented in runtime | **Update:** 2026-09-14

## English

No `cms-forum` runtime plugin is documented as part of the current `CMS/plugins/` tree. This file therefore records no executable forum workflow. Implementers must first add and register a plugin, then document its actual routes, capabilities, persistence, and views from the shipped code.

## Deutsch

Im aktuellen Verzeichnis `CMS/plugins/` ist kein Runtime-Plugin `cms-forum` als implementiert dokumentiert. Diese Datei beschreibt daher keinen ausführbaren Forum-Workflow. Vor einer Implementierung müssen Plugin, Registrierung, Routen, Capabilities, Persistenz und Views im Code vorhanden sein und anschließend aus diesem Code dokumentiert werden.
