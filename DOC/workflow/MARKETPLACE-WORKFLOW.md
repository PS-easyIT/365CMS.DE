# 365CMS – Projektdokumentation | Abschnitt: Workflow – Marketplace
> **Stand:** 2026-09-14 | **Version:** 3.4.00 | **Status:** Stable | **Update:** 2026-09-14

## English

The administrative marketplace workflow is implemented by `CMS/admin/modules/plugins/PluginMarketplaceModule.php` and `CMS/admin/views/plugins/marketplace.php`. Use the registered admin page, verify permissions server-side, and treat remote marketplace data as untrusted input.

## Deutsch

Der administrative Marketplace-Workflow wird durch `CMS/admin/modules/plugins/PluginMarketplaceModule.php` und `CMS/admin/views/plugins/marketplace.php` implementiert. Verwenden Sie die registrierte Admin-Seite, prüfen Sie Berechtigungen serverseitig und behandeln Sie externe Marketplace-Daten als nicht vertrauenswürdige Eingaben.
